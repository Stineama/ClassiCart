# ClassiCart

ClassiCart is a simple e-commerce website built using HTML, Tailwind CSS, and vanilla JavaScript. The project was created to simulate a basic online shopping experience with a clean and responsive interface.

Products displayed on the site are not hardcoded. Instead, the application integrates the DummyJSON API to fetch product data dynamically. This makes the project feel more realistic, as the products, prices, and details are coming from an external source rather than static content.

Users can browse through the products, search for specific items, and add them to a shopping cart. The cart system is handled entirely on the frontend using localStorage, which means any item added remains available even after refreshing the page. Users can also increase, decrease, or remove items from the cart, and the total price updates automatically based on their actions.

The layout was built with a mobile-first approach, ensuring that the product grid, cards, and overall spacing adapt properly across different screen sizes. Special attention was given to keeping the design simple, readable, and easy to use, especially on smaller devices.
